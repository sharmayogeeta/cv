# Yogeeta Sharma — Online CV

Live CV: https://sharmayogeeta.github.io/cv/
Portfolio: https://sharmayogeeta.github.io/portfolio/ (separate repository: `sharmayogeeta/portfolio`)

## What's here
| File | Purpose |
|---|---|
| `index.html` | The online CV (profile, experience, education, skills, publications, books) |
| `assets/css/cv.css` | Styles, including a clean print layout (Ctrl/Cmd + P) |
| `assets/Yogeeta_Sharma_CV.pdf` | Downloadable PDF version |
| `assets/img/` | Photo, quill favicon, book covers and tool logos (stored locally so they can't break) |

## Publishing
GitHub Pages serves this repository from the `main` branch (root folder). After merging a pull request, the live CV updates within a minute or two.
